# Bindi activation check

The first eight-image check found higher feature 3725 activation for bindi-visible images, but the spatial map was broad across the face and head. An expanded visual review of all 80 pilot images found the same direction in prompt-matched seed summaries, with substantial prompt adherence and styling confounds. A same-image edit attempt changed the crop, so it was rejected as a control.

**Current interpretation:** feature 3725 is a candidate associated with bindi-prompted portraits in this pilot; the evidence does not establish that it represents a bindi. The activation map is not bindi-localized. Do not use this result to claim a bindi-specific or race-specific feature, or as justification for feature ablation.
