The spatial scripts are source copies of this experiment. run.py exports the exact reused storage utility function bodies without any older generation CLI; additive.py exports only the selected face-SAE constants. No alternate SAE or generator is loaded. Scripts expect the existing /n/fs/goose research workspace, its local model cache, and previously saved baseline archives. Full executed generation snapshots are preserved locally in config/source/; evaluation snapshots are in config/evaluation_source/. See the permanent run README for exact commands. Code publication does not include model weights or raw experiment archives.
