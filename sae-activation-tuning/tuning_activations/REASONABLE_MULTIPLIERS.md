# Reasonable multiplier candidates from completed sweeps

These are visual starting points from sweeps that were already generated. I reviewed one seed-0 image grid per feature, generally from the group with the largest mean pixel change among the saved group summaries at |alpha| <= 10. Feature 138 and feature 3884 use their salient groups (Middle Eastern women and White men). Red boxes mark the tiles that look like usable candidates in that one sample.

**These are not validated safety bounds or universal clamps.** Face shape, prompt group, and feature activity vary. A proposed range should be checked across multiple seeds and groups before it becomes an automatic clamp. The original sweep images and metrics are unchanged.

## How to read the candidates

Alpha +1 is the no-op multiplier in the underlying intervention. The grids may omit +1, so the unedited original tile is the reference. Negative values suppress or reverse the selected feature direction; positive values amplify it. The candidate tiles are red-boxed; unboxed values are outside the visually selected range.

A range is useful for narrowing a follow-up sweep. It should not be applied as a global clamp across features: for example, feature 3884 shows a visible flag-background change around +15 to +30, while feature 527 only keeps the sample face coherent around 0 to +7. Feature 3611 showed no useful change in the checked sample.
